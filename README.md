# lamngockhuong/homebrew-tap

Homebrew tap for [termote](https://github.com/lamngockhuong/termote).

## Install

```sh
brew install lamngockhuong/tap/termote
```

## Upgrade

```sh
brew upgrade termote && termote restart
```

## Uninstall

```sh
termote uninstall && brew uninstall termote
```

## Maintenance

`Formula/termote.rb` is generated by the release workflow of
[lamngockhuong/termote](https://github.com/lamngockhuong/termote). Do not edit it by hand.
